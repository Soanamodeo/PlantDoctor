# PlantDoctor
Allows users to either upload or take pics of plants for identification. You're able to save your plant lists too. It also identifies weeds and plant ailments and offers cures both naturally and chemically.
You'll need an api key to access the features. To get a Gemini API key, visit Google AI Studio, sign in with your Google account, and click "Create API key". You can create the key in a new project or an existing Google Cloud project to immediately begin using the Gemini API for free. Enter that key into the pop up and you're all set.
This works for all plants including lawns, trees, shrubs, household plants, you name it. 
If you plant is reported as sick, it'll will list the cures and then after it's healed you can click on its original pic in the plant list and update the status with a new photo.
